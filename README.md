## 🎬 [토이 프로젝트] 구독 서비스 플랫폼 (TVING Clone)
> **개발 기간:** 2023.04.01 ~ 2023.05.01 (1개월)  
> **시연 영상:** [📺 YouTube 시연 영상 보기](https://youtu.be/pCAG_vlBPzI)

### 🛠️ Tech Stack
- **Front-end:** React, TypeScript
- **Back-end:** Java, Spring Boot, JPA, Spring Security, JWT, RESTful API
- **Database / Cache:** Redis, MySQL

### 📌 핵심 구현 기능
- **회원 관리:** 로그인, 로그아웃, 회원가입 (Spring Security + JWT 기반 인증)
- **구독 및 결제 시스템:**
  - 구독 상품 결제, 요금제 업그레이드 및 다운그레이드
  - 정기 결제 취소 및 재시작
  - 당월 구독 상품 및 다음 달 변동 예정 구독 상품 조회
  - 이용 내역 및 결제 내역 조회
- **사용자 편의 기능:** 콘텐츠 찜 기능 및 찜한 목록 조회
